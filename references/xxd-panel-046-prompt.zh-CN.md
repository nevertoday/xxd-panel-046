# XXD Panel 046 · 明亮厚涂微景观生成核心

严格把当前选定的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的主体、构图、配色和文案。

最终只生成当前已经锁定的**变化设计画框**：在上下双联中位于下方，在左右双联中位于右侧，在纯设计版和每张壁纸中铺满整张画布。设计画框内部不得再次出现摄影面板、分界线、边框、设备样机或预留空格。

## 0. 不可改变的美学动机

每个变化画框必须同时成立：

**当前照片中特定且可辨认的主体或不可拆分关系 → 带有真实油彩厚度的精致微缩实体 → 一条由源图推导出的斜向承托场 → 明亮鲜活而有来源的色彩 → 清透温暖的光 → 大部分暖白纹理纸面留白 → 与斜向构图共同生长的艺术出版物式精细文字。**

这不是照片滤镜、普通油画化、完整风景画、玩具模型或随意摆放主体的颜料笔刷海报。换成无关照片后，如果主体、色带、色盘、光线和文字仍几乎不用改变，成品失败。

## 1. 先锁定源图事实

在内部判断但不输出分析：

1. 找出唯一主要主体，或确实不可拆分的核心关系。
2. 锁定至少三个源图专属身份线索：轮廓、姿态／朝向、比例、材质、颜色、开口、连接、遮挡、负形或关系距离。
3. 判断源图中可成为承托场的真实依据：水面、地面、道路、路径、光线、运动方向、地形或空间关系。
4. 提取最明亮、最鲜活、最有生命力的颜色，而不是平均取色。
5. 判断光线来自哪里、哪里适合集中厚涂、哪里必须保留薄涂和裸露纸面。

不得虚构人物经历、地点、事件、所有权、情绪或象征。地点只有用户明确提供或画面证据可靠时才能写入文字。

## 2. 可辨认的厚涂微缩主体

- 将主体重构为精致、立体、可触摸的微缩景观实体，保留核心身份和关键比例。
- 允许为微景观呈现优化观察角度、比例和次要细节，但不能更换主体、改变人物身份或丢失关键关系。
- 人物保留姿态、朝向和服装大形；动物保留体态和头部方向；植物保留生长方向与体量；建筑保留天际线、开口和关键结构；器物与交通工具保留功能轮廓、负形与朝向；自然场景保留一处具体地形、水体、云、树或可辨认关系。
- 主体始终是唯一视觉核心。次要自然意象只能服务空间、光线或尺度，不得形成第二幅完整风景。
- 微缩感来自尺度、材料厚度、局部投影和空间关系，不来自玩具底座、包装盒、模型展台或塑料质感。

## 3. 一条斜向承托场与大面积留白

- 构图只有一条居中或轻微偏心的主要斜向轴；方向由源图的动作、地形、路径、光线或空间关系决定。
- 用一抹清透但具有真实颜料厚度的色带承托主体。它可转化为水面、地面、路径、光带或抽象风景切片，但必须与主体实际接触或形成明确空间支撑。
- 色带不是无意义的背景笔刷，不得在每张图里重复同一种弧线、波浪或飘带。
- 大部分画框保持明亮暖白纹理纸面。留白是光线与呼吸空间，不能被渐变、纹理噪点或装饰填满。
- 倒影、波纹、光斑、延展笔触、厚涂云层、太阳或雾气只能按源图需要少量加入；不需要时就不画。

## 4. 厚涂油画 × 微缩实体 × 清透光感

- 清楚呈现颜料堆积、刮刀痕迹、色层叠压、起伏边缘、纸张纹理、缺口和半手工塑形感。
- 厚涂集中在主体、承托色带、少量云层和局部高光；其他区域保留薄涂或裸露纸面，使厚度真正可见。
- 色彩边缘允许不规则、刮擦和微小断裂，但整体仍精致、轻盈、干净。
- 体积像油彩在纸面上隆起，不像光滑 3D 模型、树脂、陶瓷、黏土、塑料公仔或摄影棚产品渲染。
- 光线晴朗、温暖、清透；局部可以像阳光般闪亮，但不使用镜头光斑、霓虹光、金属高光、玻璃拟态或硬质商业棚拍。

## 5. 明亮且源图可解释的色彩

- 从源图选择最鲜活的主色与少量辅助色，提高明度、纯净度和冷暖清晰度，但不脱离来源。
- 清澈天空蓝、湖水青、嫩绿、暖黄、珊瑚橙、桃粉只是可能的色彩角色，不是固定色盘。
- 使用大量纯净暖白作为呼吸空间。局部暖橙、金黄或粉红可像阳光一样点亮画面，但只有源图支持时才使用。
- 整体必须晴朗、鲜活、温暖、轻快、有生命力，同时避免刺眼和廉价。
- 严禁灰脏、发旧、暗褐滤镜、低沉莫兰迪化、冷科技蓝、荧光色、彩虹渐变和糖果玩具配色。

## 6. 046 专属文字形态

文字是**艺术出版物中的精致标注**，不是通用海报大标题、实验档案墙、粗黑现代主义标题、手写涂鸦或 UI 标签。

### 文案

- 自动文案从主体身份、已知地点、可见气氛或有证据的象征意义中写一个简短标题。
- 标题应明亮、克制、有温度，可有诗意，但不强求双关、反转或“会心一击”。
- 默认一个标题；只有确有信息价值时增加零至两条极短副文。不要为了显得高级而编造年份、编号、坐标和档案标签。
- 执行换图测试：如果标题放到无关照片上仍同样成立，必须重写。
- 用户最终成稿逐字保留；用户给出方向或草稿时只在授权范围内精炼。

### 字体导演

- **角色：**校准微缩尺度与留白节奏的艺术出版物标注。
- **气质：**明亮、精确、安静、温和、精致。
- **字形：**细至常规字重，笔画清楚，字距宽松但不过分拉散；标题紧凑，副文更小。不同文字系统不机械套用固定字号比例。
- **位置：**沿斜向承托场、主体边缘或一处安静白边对齐；断行服从完整语义，不把文字散落成装饰。
- **材质：**像轻微吸入纹理纸面的油墨或干燥凸版印刷，准确可读，但不能像悬浮在画面上的光滑数字图层。
- **本地化字形：**中文和日文可使用精致宋／明朝体或克制的人文黑体；韩文保持自然现代字形与正确空格；阿拉伯文保持真实连写和从右到左的编辑排版；拉丁文字根据标题选择优雅轻量人文无衬线或克制当代衬线。不得用伪外文制造国际感。

摄影面板中绝不出现文字。无字模式中，变化画框也不得出现任何字母、汉字、数字或伪文字。

## 7. 当前模式与壁纸

调用方会在本提示词后附上已经解析完成的唯一当前模式、准确尺寸、源图可见性和锁定文字。只执行附加块中的当前值，不要自行选择模式。

- 双联设计只生成变化画框本身；摄影面板由外部独立准备和精确拼合。
- 纯设计版与壁纸不显示源照片、分界线或摄影预留区。
- 每张壁纸都为目标宽高比重新构图。系统 UI 区域保持低信息，不绘制时钟、图标、Dock、控件或设备框。
- 连贯壁纸使用原照片锁定身份和内容，定调图只锁定明亮色盘、厚涂语法、斜向场、光线、留白和文字气质；不得机械裁切或顺序垫图。

## 8. 生成前检查

1. 主体仍能通过至少三个源图专属线索被识别。
2. 只有一条源图有依据的斜向承托场，而不是通用颜料飘带。
3. 真实颜料厚度集中且有薄厚对比，不像塑料、黏土或光滑 CGI。
4. 大部分画框仍是明亮暖白纹理纸面，空间轻盈而不空洞。
5. 色彩明亮、鲜活、温暖且能从源图解释，没有灰脏、暗褐、荧光或廉价糖果感。
6. 文字内容准确，字形与 046 的精致艺术出版物气质一致，并真正沿斜向构图或安静白边参与画面。
7. 当前模式、尺寸、源图可见性、壁纸安全区和文字设置全部服从附加块。
8. 最终画面没有拼贴总览、Logo、水印、UI、样机、第二焦点或无关装饰。
